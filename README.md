# 야구맘기록지

경기를 보면서 **우리 아이가 나오는 장면만** 간단히 기록하고, 경기가 끝난 뒤 투수·타자·수비 기록을 돌아보는 모바일 웹앱(PWA)입니다.
공식 기록과는 별개로, 아이의 비공식 기록을 꾸준히 쌓는 것이 목적입니다. 야구를 잘 모르는 부모도 설명 없이 쓸 수 있게 만들었습니다.

## 주요 기능

- **상황 기준 기록 하나**: 아이가 나올 때마다 역할(투수 · 타자 · 주자 · 수비)을 고르고, 공마다 결과 버튼을 누릅니다. 이닝·아웃·카운트·주자·점수는 앱이 계산합니다.
- **상황판 고정**: 세로 화면 한 장에 상황판과 버튼이 모두 들어갑니다.
- **팝업 입력**: 투구 상세(구종 · 스트라이크 존 · 반원 구속 다이얼), 타구 기록(야구장 낙구 지점 · 타구 종류 · 세기), 아이의 수비 기록(잡아서 아웃 · 던져서 아웃 도움 · 실책), 병살.
- **분석**: 투수 · 타자 · 수비를 나누어 보고, 모든 숫자는 "계산 과정" 탭에서 공식 · 들어간 숫자 · 출처(경기 · 이닝 · 타석)를 확인할 수 있습니다.
- **경기 관리**: 이 경기 기록(스코어보드 · 장면별 기록), 경기 목록(찾기 · 정렬).
- **설정**: 오른손 · 왼손 배치, 데이터 관리(백업 JSON · 표 CSV 내려받기, 백업 불러오기).
- **도움말**: 처음 사용 안내(튜토리얼)와 사용 설명서.

## 설치 (휴대폰)

1. https://hoyasiro.github.io/baseball_counter_stat_cal/ 을 휴대폰 브라우저로 엽니다.
2. 아이폰은 Safari 공유 단추 → "홈 화면에 추가", 안드로이드는 Chrome 메뉴 → "홈 화면에 추가"(또는 "앱 설치").
3. 한 번 열어 두면 인터넷이 없어도 열립니다. (서비스 워커 `public/sw.js`)

## 배포

- `main`에 합쳐지면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트 → 빌드 → GitHub Pages 배포를 합니다.
- 처음 한 번: 저장소 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
- 빌드는 상대 경로(`vite.config.ts`의 `base: './'`)라 하위 주소에서도 열립니다.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm test           # 테스트 (Vitest)
npm run typecheck  # 타입 검사
npm run build      # 빌드 (dist/)
```

- TypeScript · Vite · Vitest. 화면 프레임워크 없이 DOM을 직접 다룹니다.
- 기록은 휴대폰 브라우저의 로컬 저장소에 저장합니다. (서버 없음)
- 폴더: `src/common`(공통: 기록 엔진 · 입력 · 경기 · 설정 · 도움말), `src/pitcher` · `src/batter` · `src/fielder`(분석별 통계와 화면), `src/app.ts`(화면 전환)
